# Ktor Server

REST API на Ktor.

## Требования
- JDK 17+

## Запуск
Запустите `Application.kt` в среде разработки или выполните команду в терминале:
```bash
./gradlew run
```
Сервер будет доступен по адресу: `http://localhost:8080`.

## Маршруты
- `GET /` — проверка работы сервера
- `GET /items` — список элементов (поддерживается фильтрация `?search=текст`)
- `GET /items/{id}` — получение элемента по идентификатору
- `POST /items` — добавление элемента (тело запроса в JSON: `{"id": 3, "name": "...", "description": "..."}`)
- `DELETE /items/{id}` — удаление элемента по идентификатору
